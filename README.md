# Alarm Clock

A multi-functional desktop alarm application built with PyQt6. Designed for Wayland on Fedora Linux.

## Usage
```bash
python3 alarm_clock.py
Features
Multiple alarms with unique labels and times.

Repeat toggles: None, Daily, Weekly (specific days), Monthly (specific date).

Configurable snooze duration.

Individual sound assignments per alarm.

Persistent JSON configuration.

Wayland native notifications via libnotify.
